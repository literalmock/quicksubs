## QuickSubs Landing (`kalakar-ai/landing`)

Astro marketing site for QuickSubs.

This is **not required** for core product development (dashboard + API + worker), but it’s useful for:

- Landing page copy / CTA
- Pricing and marketing sections
- Demo section content

## Local run

```bash
npm install
npm run dev
```

Default: `http://localhost:4321`

## Structure (where to edit)

- **Page**: `src/pages/index.astro`
- **Sections/components**: `src/components/*.astro`
- **Global styles**: `src/styles/global.css`
