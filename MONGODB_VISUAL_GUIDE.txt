                          MONGODB ATLAS SETUP

Step-by-Step Screenshots Guide:

1. SIGN UP
   └─ Go to https://www.mongodb.com/cloud/atlas
   └─ Click "Sign Up Free"
   └─ Create account with email

2. CREATE CLUSTER
   └─ Click "Create a Deployment"
   └─ Select "M0" tier (free!)
   └─ Choose region closest to you
   └─ Click "Create Cluster"
   └─ Wait 2-3 minutes for setup

3. CREATE DATABASE USER
   └─ Go to "Database Access" (left menu)
   └─ Click "Add New Database User"
   └─ Username: (choose something like 'quicksubs_user')
   └─ Password: (strong password)
   └─ Click "Add User"

4. WHITELIST YOUR IP
   └─ Go to "Network Access" (left menu)
   └─ Click "Add IP Address"
   └─ Choose "Allow access from anywhere" (or add your IP)
   └─ Click "Confirm"

5. GET CONNECTION STRING
   └─ Go to "Databases" → Your Cluster
   └─ Click "Connect" button
   └─ Click "Drivers"
   └─ Select "Node.js" version "4.x or later"
   └─ Copy the connection string
   └─ Replace <username> and <password> with your database user
