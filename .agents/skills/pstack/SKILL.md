# pstack

pstack is a collection of engineering skills created by Lauren "poteto" Tan for rigorous, verifiable software engineering.

## Main Entry Point

- **`poteto-mode`**: Core orchestrator and execution mode for non-trivial engineering tasks (`.agents/skills/poteto-mode/SKILL.md`).
- **`setup-pstack`**: Model role assignment configuration (`.agents/skills/setup-pstack/SKILL.md`).
- **`unslop`**: Eliminating bloated, cliché, and low-signal AI prose and boilerplate.
- **`how` & `why`**: Architectural investigation and historical rationale.
- **`architect`**: Parallel design exploration before implementing changes across boundaries.
- **`tdd`**: Smallest failing test first, root-cause verification.
- **`swarm` & `arena`**: Parallel review and design competitions.
- **Core Principles**: Sequence verifiable units, model the domain, prove it works, laziness protocol.
