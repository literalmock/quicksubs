                          QUICK FIX (2-3 MINUTES)
════════════════════════════════════════════════════════════════════════════════

1. GET YOUR MONGODB URI
   ──────────────────────────────────────────────────────────────
   Option A - MongoDB Atlas (Cloud):
     • Go to https://www.mongodb.com/cloud/atlas
     • Sign up free
     • Create cluster → Click "Connect" → Copy connection string
     • Add your IP to Network Access whitelist
   
   Option B - Local MongoDB:
     • Install MongoDB locally
     • Use: mongodb://localhost:27017/quicksubs

2. UPDATE .env FILE
   ──────────────────────────────────────────────────────────────
   Location: kalakar-ai/server/.env
   
   Replace: MONGODB_URI=mongodb+srv://user:password@cluster...
   With:    MONGODB_URI=mongodb+srv://YOUR_USER:YOUR_PASS@cluster0.xxxxx.mongodb.net/quicksubs?...
   
   Replace:
     • YOUR_USER with your MongoDB username
     • YOUR_PASS with your MongoDB password
     • cluster0.xxxxx with your actual cluster identifier

3. UPDATE V0 SETTINGS
   ──────────────────────────────────────────────────────────────
   1. Click Settings (top right)
   2. Go to Vars tab
   3. Update MONGODB_URI with your connection string
   4. Save

4. RESTART SERVER
   ──────────────────────────────────────────────────────────────
   cd kalakar-ai/server && npm run dev
   
   You should see:
     ✅ MongoDB connected: cluster0.xxxxx.mongodb.net
     🚀 Server running on port 5000

════════════════════════════════════════════════════════════════════════════════
                     COMMON MISTAKES & HOW TO AVOID
════════════════════════════════════════════════════════════════════════════════

❌ MISTAKE: Using placeholder URI
   ✅ FIX: Copy REAL URI from MongoDB Atlas → MongoDB Atlas → Connect

❌ MISTAKE: Wrong username/password in URI
   ✅ FIX: Double-check credentials match MongoDB Atlas Database Access

❌ MISTAKE: IP not whitelisted (MongoDB Atlas)
   ✅ FIX: Go to Network Access → Add IP Address → Whitelist your IP

❌ MISTAKE: Updating only .env, not v0 Settings
   ✅ FIX: Update BOTH .env file AND v0 Settings → Vars → MONGODB_URI

❌ MISTAKE: Not restarting server after updating .env
   ✅ FIX: Always restart with: cd kalakar-ai/server && npm run dev

❌ MISTAKE: Using local MongoDB URI for cloud MongoDB
   ✅ FIX: Use mongodb+srv://... for Atlas, mongodb://... for local

════════════════════════════════════════════════════════════════════════════════
                     TROUBLESHOOTING QUICK REFERENCE
════════════════════════════════════════════════════════════════════════════════

ERROR: querySrv ENOTFOUND _mongodb._tcp...
→ Your URI is placeholder or invalid
→ Copy real URI from MongoDB Atlas
→ Update .env AND v0 Settings

ERROR: authentication failed
→ Wrong username/password
→ Check Database Access in MongoDB Atlas
→ Update URI with correct credentials

ERROR: IP not whitelisted
→ MongoDB Atlas only - check Network Access
→ Add your IP or allow all (0.0.0.0/0)

ERROR: connect ECONNREFUSED (Local MongoDB)
→ MongoDB service not running
→ Start with: brew services start mongodb-community (macOS)
→ Or: sudo systemctl start mongod (Linux)

                      MONGODB CONNECTION STRING FORMAT
════════════════════════════════════════════════════════════════════════════════

MONGODB ATLAS:
  mongodb+srv://username:password@cluster0.xxxxx.mongodb.net/dbname?retryWrites=true&w=majority

LOCAL MONGODB:
  mongodb://localhost:27017/dbname

LOCAL WITH AUTH:
  mongodb://username:password@localhost:27017/dbname?authSource=admin

DOCKER:
  mongodb://mongodb:27017/dbname
