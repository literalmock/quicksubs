## QuickSubs MVP (`quick-subs-mvp`)

This repo contains **QuickSubs**: a small SaaS that lets users upload videos, **auto-generate subtitles**, edit them in a browser editor, and **export a burned-in video**.

The actual product code lives in `kalakar-ai/`.

## Where to start

- **Main project docs**: `kalakar-ai/README.md`
- **Dashboard (React)**: `kalakar-ai/app/README.md`
- **API (Express)**: `kalakar-ai/server/README.md` (generated by the root docs)
- **Worker (BullMQ + FFmpeg)**: `kalakar-ai/worker/README.md` (generated by the root docs)
- **Marketing site (Astro)**: `kalakar-ai/landing/README.md`

## Repo layout

```text
quick-subs-mvp/
  kalakar-ai/          # the actual app (frontend + backend + worker)
```

## Quick local run (most common)

You can start all 3 dev processes with one script:

```bash
chmod +x run-dev.sh    # first time only
./run-dev.sh
```

Or run them manually in 3 terminals:

```bash
cd kalakar-ai/server && cp .env.example .env && npm i && npm run dev
cd kalakar-ai/worker && cp .env.example .env && npm i && npm run dev
cd kalakar-ai/app && cp .env.example .env && npm i && npm run dev
```

Then open the dashboard at `http://localhost:5173`.
