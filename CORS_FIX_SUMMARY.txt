TROUBLESHOOTING QUICK LINKS
───────────────────────────────────────────────────────────────────────────────

Issue: "Backend Not Available" alert
Fix: Run npm run dev in kalakar-ai/server
Doc: FIX_CORS_AND_LOGIN.md

Issue: ERR_NETWORK in console
Fix: Check if backend is running on port 5000
Doc: CORS_TROUBLESHOOTING.md
